This module extends ``sy_crm_salesperson_planner_extended`` to allow
rescheduling visits as phone calls.

It transfers the selected opportunity and sales team, and includes the
visit's close reason and notes in the phone call description.

Usage
=====

To use this module, you need to:

1. Go to **CRM > Configuration > Settings** and select **Phone Calls**
   as the default reschedule model (optional).
2. Go to **CRM > Salesperson Planner > Visits** and open a visit.
3. Click **Cancel** or **Incident** and select a close reason that
   allows rescheduling.
4. Enable **Reschedule** and select **Phone Calls**.
5. Select an opportunity if the visit has multiple linked opportunities.
6. Enter the call date and time, summary, and description.
7. Click **Submit**.

The original visit will be closed, and a new phone call will be created
with the selected opportunity, its sales team, and the visit's close
reason and notes.
