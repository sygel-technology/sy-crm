This module extends the CRM Salesperson Planner visit closing wizard to
allow selecting a predefined phone call summary when rescheduling a
visit as a phone call.

The selected summary is assigned to the new phone call using the
``summary_id`` field provided by the OCA
``crm_phonecall_summary_predefined`` module.

Usage
=====

1. Go to **CRM > Salesperson Planner** and open a visit.
2. Close the visit using a close reason that allows rescheduling.
3. Enable **Reschedule** and select **Phone Calls**.
4. Select a predefined summary in the **Call Summary** field.
5. Complete the remaining phone call information and confirm the wizard.

The new phone call will be created with the selected predefined summary,
and its name will be automatically populated from that summary.
