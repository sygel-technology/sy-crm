To use this module, you need to:

1. Go to **CRM > Configuration > Settings**.
2. Under **Salesperson Planner**, select the **Default Reschedule Model**. By default, **Visits** is the only available option.
3. Save the configuration.
4. Go to **CRM > Salesperson Planner > Visits** and open a visit.
5. Click **Cancel** or **Incident** and select a close reason that allows rescheduling.
6. Enable **Reschedule** and select the desired option in **Reschedule To**.
7. Set the new date and sequence, then click **Submit**.

The original visit will be closed, and a new visit will be created and confirmed with the selected date and sequence.

Additional rescheduling options can be made available through other modules.
