Installation
============

To install this module, you need to:

- Only install

IMPORTANT NOTE:

Installing this module hides all Odoo's default options for Leads
autoassignment.

Configuration
=============

To configure this module, you need to:

1. Enable Lead Assignment Go to CRM → Configuration → Settings and
   enable Lead Assignment (rule-based assignment). This step is
   mandatory to display the advanced Sales Team Members layout where the
   autoassignment options of this module are available.

2. Create a stage that allows automatic assignment of opportunities by
   checking the option 'Allow autoassign'.

3. Allow automatic assignment of team members by selecting the option
   'Autoassign Opportunities'. This option can only be selected by
   members who are not teamleders.

4. Configure the number of days and the number of opportunities that can
   be assigned to each member.

5. Configure the domain of opportunities that can be assigned to a team
   member.

6. Optionally, from the sales team you can select a stage to which the
   opportunity will be transferred after being autoassigned.

Usage
=====

To use this module, you need to:

- The assignment of opportunities will be done automatically every 30
  minutes.

- It can be done manually per sales team by clicking on 'Assign
  opportunities' from the sales team view.

Note that opportunities will be assigned in order of creation date. That
is, the oldest opportunities are assigned first and then the most recent
ones.
